# 🎬 Movie Success Prediction & Analytics Dashboard

## 📌 Overview

This project is an interactive **Movie Analytics Dashboard** combined with a **Machine Learning-based prediction system** to analyze and forecast movie success.

It provides insights into movie performance across multiple film industries such as **Bollywood, Hollywood, Kollywood, and Tollywood**, using data visualization and predictive analytics.

---

## 🚀 Key Features

* 📊 Interactive dashboard built using Streamlit
* 🌍 Multi-industry dataset integration
* 🎯 Movie success prediction system
* 🔍 Advanced filtering (genre, ratings, vote average)
* 📈 Financial performance analysis (Revenue vs Trends)
* 🤖 AI-powered prediction engine

## ▶️ How to Run the Project

### 1. Clone Repository

```bash
git clone https://github.com/your-username/movie-success-prediction-ml.git
```

### 2. Navigate to Folder

```bash
cd movie-success-prediction-ml
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
streamlit run src/app.py
```
